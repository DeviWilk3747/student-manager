# Student Manager CLI

## Description

Student Manager CLI is a command-line Python application that allows users to manage student records. The application supports adding, viewing, searching, updating, and deleting students while saving data permanently using text file storage.

This project was built to strengthen Python fundamentals and practice real software development concepts such as CRUD operations, file handling, input validation, modular programming, and data persistence.

---

## Features

* Add new students
* View all students
* Search for students by name
* Update a student's major
* Delete students
* Save student data to a text file
* Automatically load saved data when the application starts
* Case-insensitive searching and updating
* Input validation and error handling

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/DeviWilk3747/student-manager.git
```

2. Navigate into the project folder:

```bash
cd student-manager
```

3. Run the application:

```bash
python student_manager.py
```
